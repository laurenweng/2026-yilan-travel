# 行程頁 NOW 標籤設計

## 目標

讓使用者回到「行程」頁時，可以立即辨識目前正在進行的行程，同時確保首頁與行程頁不會產生不同的時間判斷結果。

## 顯示規則

- NOW 標籤位於行程 title 前方。
- 非進行中的行程完全不渲染標籤，也不保留空白位置。
- 進行中的標籤固定顯示大寫 `NOW`，使用紅底白字的像素風外觀，視覺接近背包頁的 `New` 標籤。
- 同一時段若有多筆行程，所有存在於 `currentEvents` 的行程都顯示 NOW。
- 使用者查看非目前日期時，該日期沒有進行中行程，因此不顯示 NOW。
- 行程開始時間包含在進行中區間，結束時間不包含；邊界規則沿用既有 `resolveTripSnapshot`。

## 資料流

`TripHandbook` 已依有效時間計算唯一一份 `snapshot`，首頁目前也是讀取這份資料。行程頁不重新計算時間，而由 `TripHandbook` 將 `snapshot?.currentEvents ?? []` 傳入 `ItineraryView`。

`ItineraryView` 以事件 ID 建立目前進行中集合。每張行程卡依 `event.id` 判斷是否渲染 NOW 標籤，避免使用 title 或時間文字比對造成同名行程誤判。

## 元件與樣式

- `TripHandbook`：把目前進行中的事件傳給行程頁。
- `ItineraryView`：在 title 區塊依事件 ID 條件渲染 NOW。
- `globals.css`：新增 title 橫向排列樣式及 NOW 紅底白字像素標籤；標籤不得壓縮 title，長標題仍可自然換行。
- NOW 為狀態文字，不提供點擊行為。

## 例外與狀態

- 行程尚未載入、載入失敗、旅程開始前、行程空檔或旅程結束後：`currentEvents` 為空，不顯示 NOW。
- 雲端資料因 `false` 規則隱藏共同行程時，沿用套用規則後的事件與 snapshot，不會替已隱藏行程顯示標籤。
- 開發預覽與正式 live 測試時間沿用 `effectiveTime`，行程頁會和首頁同步顯示。

## 驗證

- 只有目前進行中的行程 title 前顯示 NOW。
- 同時段多筆行程全部顯示 NOW。
- 非進行中與不同日期的行程不渲染標籤。
- NOW 樣式為紅底白字，且 title 排版保持正常。
- 既有開始／結束時間邊界、共同行程取消與行程卡操作測試維持通過。
