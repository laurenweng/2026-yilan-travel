# 背包大合照設計

## 目標

將旅程完成後解鎖的最後一個背包收藏，由蘋果改為大合照。背包格位使用 `照片.svg` 作為小圖；開啟物品 Bottom Sheet 時，以接近內容區全寬的尺寸顯示 `大合照.png`，讓合照成為畫面重點。

## 資料分工

- 程式內的背包目錄管理物品 ID、顯示名稱、格位小圖、詳情大圖與舊資料別名。
- 雲端 Excel 繼續管理解鎖所屬行程與物品文案，不新增圖片欄位。
- `apple` 保留為內部物品 ID，避免破壞既有解鎖順序、已讀狀態與 localStorage 資料。
- Excel 的「解鎖對應」繼續使用 `蘋果`。程式將它視為大合照的相容別名，也接受新的顯示名稱與素材名稱。

## 物品內容

- 內部 ID：`apple`
- 顯示名稱：`大合照`
- 背包格位小圖：`照片.svg`
- Bottom Sheet 大圖：`大合照.png`
- Excel「解鎖對應」：維持 `蘋果`
- Excel「物品文案」：`結束旅程，將所有旅行的回憶都放進心裡`

## 畫面行為

- 背包最後一格在解鎖後顯示 `照片.svg`，格位尺寸、排序、New 標籤與點擊行為維持不變。
- Bottom Sheet 標題維持「物品」。
- 大合照使用獨立的詳情圖片欄位，不放大 93px 格位小圖。
- `大合照.png` 以內容區可用寬度顯示、維持原始比例，並移除只適合像素素材的 `image-rendering: pixelated` 與像素風陰影。
- 圖片下方依序顯示名稱「大合照」與 Excel 提供的物品文案。
- 其他背包物品沒有詳情大圖時，仍沿用原本的 93px 小圖樣式。

## 資料流程

1. 雲端 Excel 發布的 CSV 在旅程完成列提供 `解鎖對應=蘋果` 與新的物品文案。
2. CSV 解析器透過背包目錄的相容別名找到 `apple`，並取得名稱「大合照」與格位小圖 `照片.svg`。
3. 背包進度邏輯維持原本的旅程結束時間判斷，將 `apple` 解鎖在最後一格。
4. 使用者點擊最後一格後，Bottom Sheet 讀取該物品的詳情大圖 `大合照.png`；其他物品維持原顯示方式。

## 相容性與錯誤處理

- 保留 `apple` ID 與既有 localStorage key，已讀狀態不需遷移。
- 保留 `蘋果` 作為解析別名，避免雲端 Excel 尚未同步或快取舊 CSV 時無法解鎖。
- 若物品沒有詳情大圖，Bottom Sheet 回退至格位小圖，不產生空白內容。
- 兩張圖片皆為專案內靜態素材，不依賴 Excel URL 或外部圖片服務。

## Excel 修改

雲端 Excel 只需要修改旅程完成列的「物品文案」：

```text
結束旅程，將所有旅行的回憶都放進心裡
```

「解鎖對應」維持 `蘋果`，不需要新增或調整其他欄位。

## 驗證

- CSV 測試：`解鎖對應=蘋果` 仍解析為 `apple`，並產生名稱「大合照」與小圖 `照片.svg`。
- 背包測試：全解鎖狀態的最後一格顯示 `照片.svg`，其餘八格與順序不變。
- Bottom Sheet 測試：大合照物品使用 `大合照.png` 與大圖樣式；一般物品仍使用 93px 小圖樣式。
- 回歸驗證：背包進度、New 提示、已讀狀態、完整測試、建置與 lint 均維持通過。

## 不在範圍內

- 不新增 Excel 圖片欄位。
- 不更動旅程完成的解鎖時間。
- 不更動其他八個背包物品。
- 不調整共用 Bottom Sheet 外殼或其他行程資訊 Sheet 的版型。
